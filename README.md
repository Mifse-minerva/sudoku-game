# 🧩 Sudoku Game

A Python-based Sudoku game designed to play and solve classic $9 \times 9$ Sudoku puzzles.

---

## 🚀 Features

* **Interactive Gameplay:** Play standard Sudoku puzzles in your terminal/GUI.
* **Validation & Solver Logic:** Built-in verification ensuring numbers obey standard Sudoku rules ($1\text{--}9$ in each row, column, and $3 \times 3$ subgrid).
* **Pure Python:** Simple implementation with no heavy external dependencies required.

---

## 🛠️ Requirements

* **Python 3.x** installed on your system.

---

## ⚡ Getting Started

1. **Clone the repository:**
```bash
git clone https://github.com/Mifse-minerva/sudoku-game.git
cd sudoku-game

```


2. **Run the application:**
```bash
python suduko.py

```
